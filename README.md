# Tosaf Chipus – AI Universal Search v2.4.5

תוסף Chrome לחיפוש מקומי ומאוחד בשיחות AI, בהיסטוריית Chrome ובתוכן אתרי Web.

## מה חדש ב־2.4.5

- ייבוא שיחות מציע כעת כברירת מחדל ייבוא כותרות בלבד, עם אפשרות נפרדת לייבוא תוכן מלא.
- שיחות AI מקבלות קידומת מקור בשם, למשל `AISTUDIO- ...`, `CHATGPT- ...`, `GEMINI- ...`, `CLAUDE- ...`.
- ChatGPT מקבל כעת את הקידומת `GPT- ...` במקום `CHATGPT- ...`, גם בכותרת הטאב, גם באינדקס וגם בייבוא; רשומות ישנות עם `CHATGPT-` מומרות אוטומטית.
- הקידומת מוצגת גם בכותרת הטאב בפועל באתרים הנתמכים, כך שקל לזהות מיד מאיזה AI השיחה.
- ייבוא AI Studio מקבל גם קבצים ללא סיומת שהורדו מ־Google Drive, ומשתמש בשם הקובץ כנושא כאשר הכותרת אינה קיימת בתוך הנתונים.
- Gemini Takeout נתמך גם במבנה פעילות של `My Activity`: במצב כותרות בלבד כל שיחה מאוחדת לפי מזהה השיחה, והנושא נגזר מההודעה הראשונה כאשר Takeout אינו מספק שם שיחה שימושי.
- נוספה הרשאת API מפורשת ל־Gemini, כפתור שמירת הגדרות, כפתור שמירת מפתח וכפתור בדיקת חיבור ל־Gemini.

- תוקנה שגיאת תחביר ב־`saveSite` שמנעה מה־Service Worker להיטען.

- בעת שדרוג ממבנה המטא־דאטה הישן, רשומות Web קיימות מקבלות שם לפי כותרת העמוד ותיאור ריק, כדי למנוע ירושה של מטא־דאטה מהדומיין.

- תוקן export של `pageKeyFor` ב־db.js כדי שה־Service Worker יטען את מודול מסד הנתונים כראוי.

- מטא־דאטה נשמר כעת **לפי עמוד**, ולא לפי דומיין, עם נרמול כתובת שמסיר מזהי מעקב נפוצים. שני עמודים שונים באותו אתר אינם חולקים יותר שם ותיאור.
- ברירת המחדל לעמוד חדש היא כותרת הדפדפן כשם, ותיאור ריק עד שמוסיפים אותו.
- יצירת מטא־דאטה ב־AI מדגישה את **נושא העמוד עצמו**: שם העמוד נשען על הכותרת המקורית ואינו אמור להפוך לשם כללי של האתר; התיאור מתאר את תוכן העמוד ולא את האתר באופן כללי.
- AI מקבל טקסט גלוי/עיקרי בלבד, לא HTML. עד 20,000 תווים לכל היותר עבור יצירת מטא־דאטה.
- חילוץ הטקסט מעדיף אזורי תוכן כמו article/main ומנסה להפחית אזורי ניווט, כותרת, footer, sidebar וטפסים. כשאין אזור מתאים, מתבצע ניקוי של גוף הדף.
- נוסף Guard נגד הזרקה כפולה של `content.js`.
- במעבר בין עמודים בתוך SPA ה־MutationObserver מתחבר מחדש למכולת התוכן החדשה.
- דירוג AI מסדר את 20 התוצאות המובילות, אך אינו מוחק את שאר התוצאות.
- שגיאות חיפוש, כולל Rate Limit, מוצגות כעת ישירות ב־Side Panel.

## פרטיות

האינדקס נשמר מקומית ב־IndexedDB. אין cookies, tokens, endpoints פרטיים, telemetry, eval או remote code.

צ'אטים במצב Incognito אינם נשמרים. אינדוקס תוכן Web רגיל הוא opt-in ודחוי; ברירת המחדל היא 25 שניות.

דומיינים רגישים נפוצים מוחרגים מאיסוף תוכן, והחסימה נאכפת גם ב־Service Worker כדי למנוע עקיפה באמצעות אינדוקס ידני.

מפתח Gemini נשמר ב־chrome.storage.session ואינו מוחזר ל־UI כערך גולמי.

## Gemini

חיפוש חכם שולח רק את השאילתה. דירוג תוצאות ויצירת מטא־דאטה הם פעולות נפרדות.

יצירת מטא־דאטה מתבצעת רק לאחר לחיצה מפורשת, עם כתובת, כותרת ועד 20,000 תווים של טקסט עיקרי.

בדירוג תוצאות נשלחים ל־Gemini עד 20 תוצאות מובילות בלבד. יתר התוצאות נשארות בתצוגה המקומית.

כלי ה־AI מקבל הנחיה להתייחס לתוכן הדף ולשדות התוצאות כאל untrusted data ולא כהוראות.

## חיפוש וביצועים

החיפוש משתמש באינדקס tokens ב־IndexedDB. לכל מסמך נשמרים לכל היותר 1,000 tokens ייחודיים.

כאשר חיפוש כולל מונחי טקסט אך אין התאמות באינדקס, אין סריקה מלאה של כל המסד. סריקת fallback מלאה נשארת רק לחיפוש ללא מונחי טקסט, כגון פילטרים בלבד.

## התקנה

1. פתח `chrome://extensions`.
2. הפעל Developer mode.
3. לחץ Load unpacked ובחר את תיקיית המאגר.
4. פתח Options והפעל את האפשרויות הרצויות.

לפתיחת החיפוש: לחץ על סמל התוסף ובחלון שנפתח לחץ **🔎 פתח חיפוש**, או השתמש בקיצור **Ctrl+Shift+K**.

## Import

מצב ברירת המחדל הוא **כותרות בלבד**: נשמרים נושא השיחה, המקור, החשבון/פרופיל, כתובת ומועד, בלי תוכן ההודעות. בחירה ב־**ייבא גם את תוכן ההודעות** שומרת את תוכן השיחה לחיפוש טקסטואלי.

ChatGPT: Data Controls → Export Data → conversations.json.

Claude: Settings → Privacy → Export data.

Gemini: Google Takeout → My Activity → Gemini Apps.

Google AI Studio: קובצי JSON/JSONL במבנים נתמכים.

פורמטי הייצוא עשויים להשתנות.
