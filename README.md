# תוסף חיפוש שיחות ואתרים – Tosaf Chipus

תוסף Chrome לחיפוש מקומי ומאוחד בשיחות AI ובהיסטוריית הגלישה.

## עקרון פרטיות

האינדקס נשמר ב-Chrome Storage המקומי של התוסף.

כאשר חיפוש חכם עם Gemini מופעל, נשלחת ל-Gemini **רק השאילתה שהמשתמש הקליד** כדי להרחיב אותה למילות חיפוש. תוכן האינדקס, תוכן השיחות והיסטוריית הגלישה אינם נשלחים ל-Gemini.

אם חיפוש חכם כבוי, אין בקשת Gemini.

## שירותים

- ChatGPT
- Gemini
- Google AI Studio
- Claude
- אתרי Web רגילים
- היסטוריית Chrome

## ייבוא

Settings → ייבוא היסטוריות → בחירת קובצי JSON.

מייבא ChatGPT תומך ב-export הרשמי הנפוץ עם `conversations.json` ו-`mapping`.

ל-Claude/Gemini/AI Studio קיימים adapters לפורמטים נפוצים. פורמטי Takeout/export משתנים, ולכן יש להשוות מול קובץ הייצוא העדכני לפני הוספת adapter נוסף.

## התקנה

1. הורד את המאגר.
2. פתח `chrome://extensions`.
3. הפעל Developer mode.
4. Load unpacked.
5. בחר את תיקיית המאגר.

## הרשאות

- `history` – קריאת היסטוריית Chrome ועדכון אינדקס/מחיקה לפי פעולה מפורשת.
- `storage` – שמירת האינדקס מקומית.
- `tabs` / `scripting` – פתיחה ואיסוף תוכן.
- גישה לאתרים – לכידת תוכן שאתה פותח.

## מגבלות

התוסף אינו משתמש ב-endpoints פרטיים של שירותי AI. לכן הוא אינו "נכנס לחשבון" כדי לשאוב נתונים מאחורי הקלעים. הייבוא ההיסטורי מתבצע מקובצי export שאתה מספק.

זה מכוון: פחות שבירות, פחות הרשאות, ופחות סיכון לפרטיות.
